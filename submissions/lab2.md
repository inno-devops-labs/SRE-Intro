### 2.3 Live debugging with exec

Before Dockerfile hardening, the gateway container ran as root:

```text

```

DNS configuration inside gateway:

```text

```

Gateway calling events and payments by Compose service name:

```text
{"status":"healthy","checks":{"postgres":"ok","redis":"ok"}}
{"status":"healthy","failure_rate":0.0,"latency_ms":0}
```

`events` resolved to:

```text
172.18.0.6
```

The gateway finds the events service through Docker Compose service discovery. Containers on the `app_default` bridge network use Docker's embedded DNS server at `127.0.0.11`, which resolves the service name `events` to the current container IP `172.18.0.6`.
